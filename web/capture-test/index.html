Browser Capture Probe

Measures whether a browser can capture both sides of a call — your microphone and the far end via system audio — and how badly the far end echoes back into the mic.

How to run

  1. Start a call (or just play speech audio) in the app you want to test — Teams, Zoom, Meet.
  2. Click Start capture. When the picker appears, choose Entire Screen and tick Share system audio.
  3. Let it run ~20 seconds with the far end talking while you stay quiet, then talk yourself.
  4. Run it twice: once on speakers, once on headphones.
