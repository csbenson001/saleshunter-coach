# Security and privacy assurance

Owner: Chief Information Security & Privacy Officer  
Review cadence: quarterly and before any material data-flow change  
Last reviewed: 2026-09-14

This directory is the source of truth for the SalesHunter Coach enterprise
security posture. Product and sales claims must distinguish implemented controls
from target controls.

- [Local-first privacy architecture](local-first-privacy-architecture.md) —
  normative engineering requirements, threat model, redaction contract, and
  release gates.
- [Enterprise CISO readiness brief](enterprise-ciso-readiness.md) — data-flow
  disclosure, compliance mappings, due-diligence answers, and evidence packet.

Neither document is a certification, legal opinion, HIPAA BAA, or data processing
agreement. A control may be described as operating only when its release evidence
has been collected and the CISO gate has passed.
